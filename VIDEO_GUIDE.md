## RECORDING SETUP

### Tools Needed
- **Screen Recording:** OBS Studio (free) or Loom
- **Webcam:** Built-in laptop camera is fine
- **Microphone:** Headset mic or external USB mic (clear audio is critical)
- **Slides:** Use the `/austial-pitch-slides.html` file (opens in browser, use arrow keys to navigate)

### Recording Steps

1. **Prepare Browser Tabs**
   - Tab 1: http://localhost:4200/home (landing page)
   - Tab 2: http://localhost:4200/login (app login)
   - Tab 3: http://localhost:4200/app/marketplace (marketplace)
   - Tab 4: http://localhost:4200/admin (admin dashboard)
   - Tab 5: file:///path/to/austial-pitch-slides.html (presentation slides)

2. **OBS Studio Setup**
   ```
   Scene 1 "Intro": Webcam only (centered)
   Scene 2 "Screen + Cam": Screen capture + webcam (bottom-right corner)
   Scene 3 "Screen Only": Full screen capture
   ```

3. **Recording Workflow**
   ```
   00:00 - 00:30  Scene 1: Intro (webcam only)
   00:30 - 02:30  Scene 3: Problem slides (screen only)
   02:30 - 07:30  Scene 2: Solution demo (screen + webcam)
   07:30 - 09:00  Scene 3: Tech/Validation slides (screen only)
   09:00 - 09:30  Scene 1: Call to action (webcam only)
   ```

4. **Record Each Section Separately**
   - Record Opening → save as `01-opening.mp4`
   - Record Problem → save as `02-problem.mp4`
   - Record Demo → save as `03-demo.mp4`
   - Record Tech → save as `04-tech.mp4`
   - Record CTA → save as `05-cta.mp4`

5. **Edit Together**
   - Use iMovie, DaVinci Resolve (free), or OpenShot
   - Add transitions between sections (1 sec fade)
   - Add background music (royalty-free from YouTube Audio Library)
   - Add text overlays for key stats
   - Export as 1080p MP4

## TIPS FOR BEST RESULTS

### Audio
- **Record in a quiet room** (turn off AC, close windows)
- **Test microphone levels** before recording
- **Speak clearly and slowly** (you can always speed up in editing)
- **Re-record if you stumble** (edit sections together later)

### Video
- **Lighting matters:** Face a window or use desk lamp (no backlighting)
- **Clean background:** Blur background in OBS if needed
- **Steady camera:** Use laptop stand or stack books
- **Look at camera** during webcam sections (not screen)

### Demo
- **Practice the demo flow** 3 times before recording
- **Have test data ready** (sample documents, pre-seeded assets)
- **Clear browser cache** between takes for clean demo
- **Highlight cursor** in OBS (Settings → Sources → Mouse Cursor: Yellow highlight)

### Editing
- **Cut out pauses** longer than 2 seconds
- **Add captions** for key numbers (OBS text overlay)
- **Background music at 20% volume** (don't drown out voice)
- **Keep final video under 10 minutes** (YouTube attention span)
